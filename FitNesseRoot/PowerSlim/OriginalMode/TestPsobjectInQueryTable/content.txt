!2 Query results with nested PSObject properties are serialized with !-ConvertTo-Json-!
The nested properties use [ordered] so the JSON key order is deterministic (plain hashtable order changes between processes)

!|Query:Local     |New-Object PSObject -property @{ title = 'test PSObject'; item1 = 'item1 value'; item2 = 'item2 value'; item3 = 'item3 value'; array = ('array item1', 'array item2', 'array item3'); psobject_item = New-Object PSObject -property ([ordered]@{ property1 = 'property1 value'; property2 = 'property2 value' }) }|
|title            |array                                                                     |item1                                     |item2                                     |item3                                     |psobject_item                                                                              |
|!-test PSObject-!|!-["array item1","array item2","array item3"]-!                           |!-item1 value-!                           |!-item2 value-!                           |!-item3 value-!                           |!-{"property1":"property1 value","property2":"property2 value"}-!                          |

!|Query:Local     |New-Object PSObject -property @{ psobject_item = New-Object PSObject -property ([ordered]@{ property1 = 'property1 value'; property2 = 'property2 value' }) }|
|psobject_item                                                                              |
|!-{"property1":"property1 value","property2":"property2 value"}-!                          |
