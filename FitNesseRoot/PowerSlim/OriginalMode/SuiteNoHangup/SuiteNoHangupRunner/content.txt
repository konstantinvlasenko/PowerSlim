This page executes the Suite tests via a nested !-FitNesse-! command line run. This is done to test for expected exceptions on the tests, which can't be tested directly from a test table because the expected result is in fact an exception.
!include -c .PowerSlim.OriginalMode.SuiteExceptions.ScenarioLibrary

!*****> Define scenario for the nested test run
''EXCEPTION_TEXT is a regular expression: socket error messages differ between Windows, Linux and macOS''

|scenario|test page|TESTPAGE                                                              |results should contain|EXCEPTION_TEXT|
|$URL=   |eval     |'@TESTPAGE?test'                                                     |
|eval    |$results = Run-Test '$URL'                                                                                            |
|check   |eval     |$results.testResults.result.content -match '@EXCEPTION_TEXT'|True                                          |

******!

!| test page results should contain                                                                                                 |
|TESTPAGE                                            |EXCEPTION_TEXT                                                                |
|PowerSlim.OriginalMode.SuiteNoHangup.TestBasicHangup|(target machine actively refused it!-|-!Connection refused)                  |
|PowerSlim.OriginalMode.SuiteNoHangup.TestNonSlimData|class="pass">3<                                                               |
