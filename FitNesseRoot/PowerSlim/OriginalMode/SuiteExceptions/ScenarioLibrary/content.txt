Create the function used to run the tests. It runs the page in a nested !-FitNesse-! through the command line (no HTTP server required) and returns the XML report.
The nested run talks to its own !-PowerSlim-! over stdin/stdout, so it never collides with the instance running this page.
|script|
|eval  |!-
function global:Run-Test ($page) {
  $output = java -jar fitnesse-standalone.jar -o -p 8024 -c "$page&format=xml" | Out-String
  # [char]60 is the less-than sign; a literal XML declaration in this cell would be parsed as markup by FitNesse
  $start = $output.IndexOf([char]60 + '?xml')
  if ($start -lt 0) { throw "No XML report for '$page': $output" }
  return [xml] $output.Substring($start)
}
-!||
